# Future improvements

This page collects known limitations of SQANTI3 that have been analysed but not yet fixed. Each
section describes the current behaviour, the evidence, and candidate fixes to test before
implementation.

---

## RTS_stage: over-prediction of RT-switching on good transcripts

**Status:** analysed, not implemented (October 2026).
**Reported problem:** users see `RTS_stage = TRUE` on transcripts that look correct, including
annotated reference transcripts.

### How RTS_stage is currently computed

`RTS_stage` is set in `process_rts` (`src/qc_computations.py`). The junction search itself lives in
`src/utilities/rt_switching.py`.

1. **Entry point.** `process_rts` is called from `qc_pipeline.py` (and `parallel.py` for chunked
   runs) on the temporary `<prefix>_junctions.txt_tmp` file:
   ```python
   RTS_info = rts([outputJuncPath + "_tmp", genome, "-a"], genome_dict)
   RTS_stage = "TRUE" if pbid in RTS_info else "FALSE"
   ```
   An isoform is flagged if **any** of its junctions is flagged. The value is the string
   `"TRUE"`/`"FALSE"`.
2. **Junction loading** (`loadSpliceJunctions`). Each unique junction (chrom, strand, start, end) is
   tested once. `sj_seen_relations` stores every isoform–junction pair that uses it, so a hit is
   propagated to every isoform sharing that junction.
3. **Sequence windows** (`checkSJforRTS`). Window length is `PATSEQLEN + 2 * wiggle = 12`. On the
   `+` strand:
   - `seq_exon`: last 11 bases of the upstream exon + first intron base.
   - `seq_intron`: last 11 bases of the intron + first base of the downstream exon.

   On the `-` strand the same windows are taken and reverse-complemented.
4. **Repeat search** (`checkForRepeatPat`). Looks for an exact seed of `min_match // 2 = 4` bases
   from `seq_exon` anywhere in `seq_intron`, extends it exactly, then requires the remaining bases
   up to `min_match = 8` to match forward or backward, with at most 1 mismatch (`-a`). The first hit
   returns `True`.
5. **Junctions tested.** All of them: canonical and non-canonical, known and novel (`-t a`, `-c a`).
   Mono-exonic isoforms are always `FALSE`.

**Parameters.** None of these are exposed in `sqanti3_qc.py`; they are fixed by `process_rts` and
the defaults of `get_parser()` in `rt_switching.py`:

| Parameter | Value |
|---|---|
| `min_match` | 8 |
| `wiggle_count` | 1 |
| `allow_mismatch` | on (`-a`, at most 1 mismatch) |
| `include_type` / `include_category` | all (`a`) |

**Outputs.**

- `RTS_stage` column in `*_classification.txt`.
- `RTS_junction` column in `*_junctions.txt`.
- `<dir>/RTS/sj.rts.results.tsv`: one row per flagged isoform–junction pair, with both windows, the
  matched pattern, its length and the number of mismatches.

**Where it is used.**

- **Rules filter.** `src/utilities/filter/filter_default.json` requires `"RTS_stage": "FALSE"` for
  every category except FSM.
- **Rescue.** Rescue runs QC and the rules filter on the reference transcripts, so flagged reference
  transcripts can fail as rescue targets.
- **QC report.** RTS plots by structural category and junction type (`SQANTI3_report.R`).
- **SQANTI-reads.** Reads the column as a boolean (`sqanti_reads_plots.py`).

### What the literature says

- Cocquet J, Chong A, Zhang G, Veitia RA. *Reverse transcriptase template switching and false
  alternative transcripts.* Genomics 2006;88(1):127–131.
  [doi:10.1016/j.ygeno.2005.12.013](https://doi.org/10.1016/j.ygeno.2005.12.013).
  Template-switching artifacts are "a significant portion of apparently spliced sequences using
  noncanonical splice signals but are rare in the context of the whole database". The risk is
  highest when the putative intron is flanked by direct repeats and the RT enzyme is poorly
  thermostable.
- Houseley J, Tollervey D. *Apparent non-canonical trans-splicing is generated by reverse
  transcriptase in vitro.* PLoS One 2010;5(8):e12271.
  [doi:10.1371/journal.pone.0012271](https://doi.org/10.1371/journal.pone.0012271).
  Proposes that most reported non-canonical splicing events in metazoans are RT template-switching
  artifacts.
- Tardaguila M, et al. *SQANTI: extensive characterization of long-read transcript sequences for
  quality control in full-length transcriptome identification and quantification.* Genome Res
  2018;28(3):396–411. [doi:10.1101/gr.222976.117](https://doi.org/10.1101/gr.222976.117).
  The original SQANTI paper, where `rt_switching.py` comes from. Still to check in the full text:
  whether the 8-base, 1-mismatch setting was validated.

Neither of the first two papers gives a reason to expect RTS artifacts at canonical, annotated
junctions. SQANTI3 currently tests those junctions too.

### Evidence: false-positive rate on a reference annotation

Measured with the current algorithm on every junction of
`test/test_data/reference/test_reference.gtf` against `test/test_data/genome/genome_test.fasta`
(chr22): 6,198 unique junctions, 5,948 of them canonical GT-AG. See the
[analysis script](#analysis-script) below.

**Per junction:**

| Set | Flagged |
|---|---|
| Real reference junctions, current settings | **2.5%** |
| Real reference junctions, exact match (no mismatch) | 0.4% |
| Random 12-base sequence pairs | 0.7% (exact: 0.1%) |
| Exon window paired with the intron window of a *different* junction | 1.5% (exact: 0.1%) |

Both windows end in the splice-site consensus. `AGG` is the most common 3-base ending of both the
exon window (3,400 / 6,198) and the intron window (2,978 / 6,198). The intron window also covers the
low-complexity polypyrimidine tract. Together these roughly double the chance match rate before any
real repeat is involved.

**Per transcript** (`RTS_stage = TRUE` if any junction is flagged):

| Junctions per transcript | Reference transcripts | RTS_stage TRUE (current) | RTS_stage TRUE (exact match) |
|---|---|---|---|
| 2–4 | 905 | 6.9% | 0.7% |
| 5–9 | 475 | 12.2% | 2.7% |
| 10–19 | 429 | 25.2% | 3.7% |
| 20+ | 120 | **35.8%** | 8.3% |
| All | 1,929 | **14.0%** | 2.3% |

About 1 in 7 annotated multi-exon transcripts, and more than a third of those with 20+ junctions,
are flagged as RTS. Combined with the default rules filter, non-FSM isoforms that share an annotated
junction with a chance repeat are removed.

**Alignment of the two repeat copies.** For the 155 flagged junctions, the offset between the copy
in the exon window and the copy in the intron window was:

| Offset | -4 | -3 | -2 | -1 | 0 | +1 | +2 | +3 | +4 |
|---|---|---|---|---|---|---|---|---|---|
| Junctions | 6 | 12 | 4 | 17 | 87 | 12 | 4 | 9 | 4 |

About 20% of the hits have copies 3–4 bases apart. `checkForRepeatPat` accepts a match at any
position in either window, so the wiggle only widens the windows; nothing keeps the two copies
within ±wiggle of each other, as the diagram in `rts()` implies.

**Caveat:** this is a single chr22 annotation. Rates should be re-measured on full human and mouse
annotations, and ideally on a long-read dataset with orthogonal support (short-read junction
coverage, CAGE).

### Candidate fixes (to test)

In order of how well each is justified:

1. **Only test novel junctions.** Already supported by `rt_switching.py` through `-c n`; it would
   be a change to the arguments in `process_rts`. Matches the literature, and annotated junctions
   are real by definition. Expected to remove most reference false positives.
2. **Require an exact match, or a longer one** (e.g. `min_match` 10). Removing the mismatch alone
   drops the per-junction rate from 2.5% to 0.4% on reference junctions.
3. **Constrain the alignment of the two copies** to the same window position ± wiggle in
   `checkForRepeatPat`, as originally intended.
4. **Expose the parameters** in `sqanti3_qc.py` (e.g. `--rts_min_match`, `--rts_allow_mismatch`,
   `--rts_junctions {all,novel,non_canonical}`) so users can tune them.

Any of these changes `RTS_stage` values and therefore the output of the default rules filter and of
rescue. Document it in the version history when implemented.

**Suggested validation:**

- Re-run the analysis script for each option on full GENCODE human and mouse annotations. Target: a
  low `RTS_stage = TRUE` rate on reference transcripts.
- On a real long-read dataset, compare RTS-flagged novel junctions against short-read junction
  support. True RTS artifacts should have little or no short-read support.
- Check that RTS rates stay high for non-canonical novel junctions, the population where the
  literature expects artifacts.

### Related bug: RTS_junction left as `????`

`write_junction_output` (`src/qc_output.py`) only fills in `RTS_junction` for isoforms present in
`RTS_info`:

```python
if r['isoform'] in RTS_info:
    r['RTS_junction'] = 'TRUE' if r['junction_number'] in RTS_info[r['isoform']] else 'FALSE'
```

Junctions of isoforms with no RTS hit keep the placeholder `????`; in a test run that was 105 of 131
unique junctions. The reports only count `== 'TRUE'`, so nothing breaks, but the column is wrong.
Fix: set `'FALSE'` in the `else` branch.

The docstring of `checkSJforRTS` also says `dict[isoform] = []` means "no RT junctions", but the
code never creates an empty entry: isoforms only appear in the result if they have a hit.

### Analysis script

Run from the repository root inside the SQANTI3 environment. It uses `checkForRepeatPat` from the
codebase, so it measures the current behaviour.

```python
import random, re, sys
from collections import Counter, defaultdict
from Bio import SeqIO
sys.path.insert(0, ".")
from src.utilities.rt_switching import checkForRepeatPat

GENOME = "test/test_data/genome/genome_test.fasta"
GTF = "test/test_data/reference/test_reference.gtf"
MIN_MATCH, WIGGLE, PATSEQLEN = 8, 1, 10

genome = {r.id: r for r in SeqIO.parse(GENOME, "fasta")}

# Exons per transcript -> junctions (1-based first/last intron base, as in *_junctions.txt)
exons = defaultdict(list)
for line in open(GTF):
    f = line.rstrip("\n").split("\t")
    if len(f) < 9 or f[2] != "exon" or f[0] not in genome:
        continue
    tid = re.search(r'transcript_id "([^"]+)"', f[8]).group(1)
    exons[(tid, f[0], f[6])].append((int(f[3]), int(f[4])))

def tx_junctions(chrom, strand, ex):
    ex = sorted(ex)
    return [(chrom, strand, e1 + 1, s2 - 1) for (_, e1), (s2, _) in zip(ex, ex[1:])]

juncs = sorted({j for (t, c, s), ex in exons.items() for j in tx_junctions(c, s, ex)})

def windows(chrom, strand, strpos, endpos):
    # Same coordinates as checkSJforRTS
    cnt = PATSEQLEN + 2 * WIGGLE
    g = genome[chrom]
    if strand == "+":
        s = strpos - cnt + WIGGLE - 1
        e = endpos - cnt + WIGGLE
        return str(g.seq[s:s + cnt]).upper(), str(g.seq[e:e + cnt]).upper()
    e = strpos - WIGGLE - 1
    s = endpos - WIGGLE
    return (str(g[s:s + cnt].seq.reverse_complement()).upper(),
            str(g[e:e + cnt].seq.reverse_complement()).upper())

W = {j: windows(*j) for j in juncs}

def rate(pairs, mismatch):
    return sum(checkForRepeatPat(a, b, MIN_MATCH, mismatch)[0] for a, b in pairs) / len(pairs)

print(f"Reference junctions: {len(juncs)}")
print(f"  flagged (1 mismatch): {rate(W.values(), True):.1%}")
print(f"  flagged (exact):      {rate(W.values(), False):.1%}")

random.seed(1)
rnd = lambda n: "".join(random.choice("ACGT") for _ in range(n))
R = [(rnd(12), rnd(12)) for _ in range(20000)]
print(f"Random pairs: {rate(R, True):.1%} (1 mismatch), {rate(R, False):.1%} (exact)")
vals = list(W.values())
idx = list(range(len(vals))); random.shuffle(idx)
X = [(vals[i][0], vals[k][1]) for i, k in enumerate(idx)]
print(f"Shuffled exon/intron windows: {rate(X, True):.1%} (1 mismatch), {rate(X, False):.1%} (exact)")
print("Most common window endings:",
      Counter(a[-3:] for a, _ in vals).most_common(3),
      Counter(b[-3:] for _, b in vals).most_common(3))

# Per transcript: RTS_stage = TRUE if any junction is flagged
hit = {j: checkForRepeatPat(*w, MIN_MATCH, True)[0] for j, w in W.items()}
hit_exact = {j: checkForRepeatPat(*w, MIN_MATCH, False)[0] for j, w in W.items()}
bins = defaultdict(lambda: [0, 0, 0])
for (t, c, s), ex in exons.items():
    js = tx_junctions(c, s, ex)
    if not js:
        continue
    n = len(js)
    b = "2-4" if n <= 4 else "5-9" if n <= 9 else "10-19" if n <= 19 else "20+"
    bins[b][0] += 1
    bins[b][1] += any(hit[j] for j in js)
    bins[b][2] += any(hit_exact[j] for j in js)
for b in ["2-4", "5-9", "10-19", "20+"]:
    n, h, x = bins[b]
    print(f"{b:>6} junctions: {n:5d} transcripts, RTS_stage TRUE {h/n:.1%} (exact: {x/n:.1%})")
```

Change `GENOME` and `GTF` to run it on a full annotation. To test candidate fix 1, keep only novel
junctions, which requires a SQANTI3 `*_junctions.txt` file rather than the reference GTF. To test
fix 3, add a position constraint to a copy of `checkForRepeatPat`.
